# Auto 路由评分持久化

本功能只保存真实业务请求已经产生的评分，不进行主动测活。

## 被动学习边界

评分来源仍是现有 auto 请求反馈。启动、定时保存、空闲、历史衰减和冷却到期都不会发送上游请求，也不会发影子请求、并行探索请求或调用另一个模型给答案打分。

没有新业务请求，就不会有新的健康观测。某个组合冷却到期后，只是重新具备被正常请求选择的资格，不代表已经恢复健康，也不会自动发请求验证它。

项目原有的手动渠道测试，以及独立配置的自动渠道测试、模型列表更新等功能不由评分持久化开启。不要为了积累评分开启 `CHANNEL_TEST_FREQUENCY` 或监控设置中的自动渠道测试。

## 保存什么

模型摘要与渠道摘要独立保存到 `auto_model_scores`：

* `scope=model`：键是分组、模型、渠道。
* `scope=channel`：键是分组、渠道，`model` 为空。它不是渠道级冷却。
* 保存原始成功率摘要、延迟摘要、有效观测数、最后实际观测时间和格式版本。
* 不保存请求正文、模型回答、API 密钥或渠道凭据。

不能从每个模型的最终分数取平均来重建渠道分。渠道分仍由实际反馈按原顺序独立更新。

## 时效与持久化不是一回事

评分算法不变:成功率和延迟使用原有 EWMA,最终分数继续考虑有效观测数与延迟。没有新观测超过衰减窗口(`AutoModelScoreDecayMinutes`,默认三十分钟)的历史回到中立状态。

衰减窗口必须长于抖动冷却窗口(十五分钟),否则冷却一到期评分就已经归零,那个组合会带着零记忆回到候选池,惩罚与教训脱节,持久化也只剩"重启很快"这一种场景有意义。这个窗口可以在后台面板调整,`AUTO_MODEL_SCORE_DECAY_MINUTES` 只是启动种子。

持久化解决的是进程重启丢失仍有效的观测,不会把短期健康信号变成永久信誉。恢复与落库不得把旧观测时间改成启动或保存时间。无效、过期及不支持的格式版本不能影响选路。保留窗口跟随同一个衰减窗口。

## 存储与故障边界

运行时继续使用内存评分。后台任务每五秒批量保存发生变化的观测，数据库操作有超时边界，失败后保留待保存状态并重试。这个周期是落库周期，不是测活周期。

同一捕获批次的模型分与渠道分在数据库事务中保存。数据库写入期间不持有评分更新锁；写入时产生的新反馈不能被旧批次清掉。旧快照不得覆盖数据库中观测时间更新的快照。

服务退出回调会尝试保存，但当前程序的信号退出路径可能直接终止进程，不能保证执行 Go 的 defer。崩溃、强制终止、保存周期内重启或数据库持续不可用时，最新未落库的评分可能丢失。本功能不承诺零丢失；已经确认保存的有效快照可以在下次启动恢复。

共享数据库上的多实例复用的是各键最近观测的快照，不是分布式 EWMA 事件合并，也不实时同步实例内存。不要将此功能宣传为全局一致的多实例学习器。

## 不改变的规则

* 分组授权与顺序、渠道优先级、渠道评分/权重、渠道内模型评分/权重。
* 每个真实请求的重试预算、已尝试组合去重、计费和响应内容。
* `(分组, 模型, 渠道)` 的严格冷却。没有渠道级永久封禁，也没有全部冷却时强行测活的兜底。
* 原有反馈归因:未进入上游发送流程的本地拒绝,不新增模型或渠道健康观测。

不引入 Redis、学习模型、Peak EWMA 或 P2C。衰减窗口与确定性失败关键词可在后台面板调整,不需要新的环境变量。

## 隔离验证

回归只能使用新建数据库和假上游。脚本必须先确认独立网络命名空间没有对外通信通路，才允许启动监听所有地址的测试网关。

隔离校验由五个回归脚本共用。只允许活动的 loopback，以及经完整接口、地址和路由检查确认未启用、未配置的内核默认隧道设备。未知接口、非本地路由或读取失败一律拒绝运行，不提供跳过开关，也不改宿主机网络。运行期间必须独占该命名空间；前后快照不能阻止另一个特权进程随后改网。

```bash
unshare --net -- sh -c 'ip link set lo up && exec python3 -B scripts/test-auto-score-persistence.py "$@"' sh /absolute/path/to/test-binary --cache both
unshare --net -- sh -c 'ip link set lo up && exec "$@"' sh python3 -B -m unittest discover -s scripts -p test_auto_score_persistence.py -v
```

脚本记录逐例结果、假上游收到的实际请求数、响应、保存/重启证据和测试二进制 SHA256。退出码 0 表示通过，1 表示行为断言失败，2 表示环境或测试装置错误。空闲观测必须有时间窗口，且其负对照必须能抓住一个额外请求。
